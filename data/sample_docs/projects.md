# Projects & Hackathons

### 1. PawPick — Co-Founder & Backend Developer (2025 – Present)
- **Type**: Academic & Solidarity Project
- **Overview**: A web and mobile platform designed to streamline animal management and matching for animal shelters.
- **Key Contributions**:
  - Co-founded the initiative and architected the mobile backend, public REST APIs, and a comprehensive administration panel for partner shelter associations.
  - Designed and implemented a custom matching algorithm based on lifestyle compatibility and animal needs to foster responsible adoptions.

### 2. BaselHack — Hackathon Participant (Nov 2024)
- **Organization**: Memox Basel (Switzerland)
- **Overview**: An AI-powered image analysis tool that automatically generates technical guide sheets.
- **Key Contributions**:
  - Built computer vision pipelines using AI to inspect and interpret technical diagrams and imagery.
  - Streamlined technical documentation creation by automating layout structuring and image processing workflows.

### 3. MyRag — GitHub Page AI Assistant (2026)
- **Repository**: [https://github.com/sramstein/MyRag](https://github.com/sramstein/MyRag)
- **Overview**: A plug-and-play Retrieval-Augmented Generation (RAG) assistant and embeddable widget for GitHub Pages and developer portfolios.
- **Technologies**: Python, FastAPI, Qdrant (free vector DB), FastEmbed / Google Gemini, Docker, Vanilla JS.
- **Key Features**: Free embedded and cloud vector database, multi-format ingestion, real-time SSE token streaming, and source citations.
